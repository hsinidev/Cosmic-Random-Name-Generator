## Key Features

-   ✨ **Customizable Generation:** Choose the quantity, gender (Male, Female, Any), and format (Full Name, First Name, Last Name).
-   🚀 **Bulk Generation:** Instantly generate lists of up to 50 names at a time.
-   🔒 **Secure & Private:** All name generation is handled client-side with pure JavaScript. No data is ever sent to a server.
-   📋 **Copy to Clipboard:** Easily copy the entire generated list with a single click.
-   🌌 **Stunning UI/UX:** A sleek, dark-mode interface with an animated cosmic background for a unique user experience.
-   📱 **Fully Responsive:** Designed to work seamlessly on desktops, tablets, and mobile devices.
-   📈 **SEO Optimized:** Includes a comprehensive article on placeholder data, full JSON-LD schema, and other SEO best practices.

## Why Choose Cosmic Name Generator?

In a world of generic tools, the Cosmic Name Generator stands out by providing a powerful, fast, and enjoyable experience.

-   **For Designers:** Test your UI layouts with variable name lengths and formats to ensure your designs are resilient and beautiful.
-   **For Writers & Gamers:** Find the perfect character names for your next story or game with endless creative possibilities.

## How to Use

1.  **Select Quantity:** Choose how many names you need (1-50).
2.  **Filter by Gender:** Select 'Male', 'Female', or 'Any'.
3.  **Choose Format:** Decide if you want a 'Full Name', 'First Name Only', or 'Last Name Only'.
4.  **Click Generate:** Hit the "Generate Names" button.
5.  **Copy Your List:** Click "Copy List" to instantly save the names to your clipboard.

## Tech Stack

-   **Styling:** Tailwind CSS
-   **Core Logic:** Pure TypeScript/JavaScript (no backend required)
-   **In-browser Transpilation:** Babel Standalone

## Local Development

To run this project locally:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/hsinidev/cosmic-random-name-generator.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd cosmic-random-name-generator
    ```
3.  **Install dependencies:**
    ```bash
    npm install
    ```
4.  **Run the development server:**
    ```bash
    npm start
    ```

The application will be available at `http://localhost:3000`.
